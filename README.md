# QSL-CARD-Report-Writer
# QSLカード レポート面 自動印刷ツール

アマチュア無線のログソフト　CTEST WIN が出力した ADIF ログから、QSLカードのレポート面(裏面)に印字するPDFを作るツールです。
事前に印刷済みのQSLカード(100×148mm・縦)に、交信データだけを重ね刷りする前提で作っています。

## 特長

- ADIF(`.adi` / `.adif`)を読み込み、1交信 = 1ページ(1カード)のPDFを作成
- **重複防止**: 印刷済みの交信を記録し、次回からは未印刷分だけを自動選択
- **QSL#** はアプリ独自の連番を印字(ログとの対応は `printed.json` に保存)
- 移動局(`JA3ABC/P` など)は、TO RADIO下の点線欄にコール+`/P` も印字
- MODE は 2WAY 欄、周波数(MHz)は MHz 欄に印字
- Ant 欄はログのバンドから自動入力
- 日本語の印字に対応(Rmks.、OP名、QTH など)

## 印字される内容

| 欄 | 内容 |
| --- | --- |
| TO RADIO(赤枠) | 相手局コール(`/P` などを除いた本体) |
| TO RADIO 下の点線 | 移動局のときだけ「コール/P」 |
| DATE | `11 OCT 2025` 形式 |
| JST/UTC | `1204 JST` 形式 |
| RST | ログの `RST_SENT` |
| MHz | バンドから換算した周波数(80m → 3.5) |
| 2WAY | MODE(SSB / CW / FM など) |
| QSL# | アプリ独自の連番 |
| Rig / Output | 設定画面で入力した値 |
| Ant | バンドから自動(下記) |
| Rmks. | 「TNX FB QSO.」+「今後ともよろしくお願いします。」(設定で変更可) |
| OP. / QTH. | ログの `OPERATOR`(または設定のOP名)/ 設定のQTH |

PSE QSL / TNX の□と 2WAY の手書き部分は印字しません(手書き用)。

### Ant の自動判定

| バンド | 印字 |
| --- | --- |
| 3.5MHz(80m) | 1/2λDP |
| その他のHF(160m〜10m) | 1λワイヤーアンテナ |
| 2m / 430MHz(70cm) | GPアンテナ |
| 上記以外 | 設定の「Ant」欄の値 |

ルールを変えたいときは、`qsl_tool.py` 冒頭の `ANT_RULES` を書き換えてください。

###CTEST WIN

- 2.写真の条件でOKを選択。ファイル保存

 ### GUI
```
python qsl_tool.py
```
1. 「ADIFを開く」で先ほど生成したADIFファイルを読み込む(未印刷の交信だけが選択された状態になります)
2. 「設定」で Rig・Output・QTH などを入力して保存
3. 「PDF作成」でPDFを保存し、印刷する


## 設定

設定画面の値は `qsl_config.json` に保存されます。

- **ADIFの時刻 / 印字する時刻**: JST か UTC を選べます(初期値はどちらも JST)
- **X補正・Y補正(mm)**: プリンタの紙送りによるズレの補正→作者環境では、特にもんだがなかったので未検証
- **台紙画像**: 白紙カードのスキャン画像を指定すると、台紙と重ねたPDFで位置を確認できます(実際の印刷時は空にしてください)→未検証
- **日本語フォント**: 空なら自動検出(Windowsのメイリオ等)。見つからないときはPDF内蔵の日本語フォントを使います。指定する場合は `.ttf` / `.ttc` のパスを入れてください

印字位置は `qsl_tool.py` 冒頭の `POS`(白紙スキャン 896×1340px 上の座標)で調整できます。別デザインのカードを使う場合は、この値を合わせてください。

## 重複チェックについて

コールサイン・日付・時刻・バンド・モードの組み合わせを `printed.json` に記録し、同じ交信を二重に印刷しないようにしています。再印刷したい交信は、一覧で手動選択すると確認ダイアログが出ます。

## 注意

- `qsl_config.json` と `printed.json` には、設定や印刷履歴が入ります。共有・公開する場合は含めないでください。
- ログ(ADIF)には他局のコールサインや交信記録が含まれます。
- カードのデザインや台紙のスキャン画像は、権利者の許可なく配布しないでください。
- 対応しているのは CTEST WIN V4.59 形式の ADIF で確認した範囲です。他のログソフトのADIFでは、項目名の違いにより動かない場合があります。
